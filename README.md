
# CryptoProg

Лабораторная работа №4. Криптография на C++ в Linux.

Используемая библиотека: Crypto++.

## Задание 1. Хеширование

Программа hash вычисляет SHA-256 содержимого файла
и выводит хеш в шестнадцатеричном виде.

Сборка и запуск:

cd hash
make
./hash

Проверка:

sha256sum text.txt

## Задание 2. Шифрование файлов

Программа cipher поддерживает:
- AES-256-CBC
- Twofish-CBC
- Шифрование и расшифрование файлов
- Формирование ключей из пароля через PBKDF2
- Проверку целостности с помощью HMAC-SHA256

Сборка и запуск:

cd cipher
make
./cipher

Проверка:

cmp secret.txt decrypted.txt

При совпадении файлов команда cmp
завершается с кодом 0.

## Установка зависимостей

sudo apt update
